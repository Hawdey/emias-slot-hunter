# ЕМИАС: охотник за слотами

Неофициальный скрипт для Tampermonkey. Проверяет расписание в открытой вкладке ЕМИАС и помогает записаться по направлению или перенести существующий приём. Для переноса к конкретному врачу включите **«Только тот же врач»**.

Неофициальный форк [polinalamponi/emias-slot-hunter](https://github.com/polinalamponi/emias-slot-hunter) на основе версии 0.1.6. Исходный проект написала Полина. Лицензия [MIT](LICENSE) включена в готовый скрипт.

## Что изменено в форке

- **Перенос к тому же врачу.** На втором шаге мастера можно включить «Только тот же врач». По умолчанию галочка выключена. Если врач не определился из текущей записи, его можно выбрать из списка ЕМИАС. Имя видно в холостом прогоне и в карточке подтверждения, когда ЕМИАС его передаёт.
- **Проверка перед записью.** Скрипт заново читает список приёмов и проверяет накладки. При неизвестном результате запись не повторяется автоматически. По умолчанию требуется подтверждение, а поиск по цели заканчивается после первого подтверждённого успеха.
- **Настройки и токены в памяти вкладки.** Поиск останавливается при смене полиса или выходе из аккаунта. После перезагрузки вкладки нужно запустить его заново.
- **Ручное обновление.** Готовый скрипт можно сверить со сборкой из исходников. Новую версию нужно установить вручную в Tampermonkey.

В форке сохранены исправления оригинала 0.1.6: защита от записи после остановки, общий выбор лучшего слота среди кабинетов и интервал проверки от 30 секунд.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) в браузере. Если уже пользуетесь исходным охотником, отключите его перед установкой форка.
2. Откройте [готовый скрипт](dist/emias-slot-hunter.user.js) и скопируйте весь файл через **Raw**. В панели Tampermonkey выберите **«Создать новый скрипт»**, замените содержимое редактора и сохраните. Для обновления откройте существующий скрипт **«ЕМИАС: охотник за слотами (личная версия)»** и замените код там. Автообновления отключены.
3. Войдите на [emias.info](https://emias.info/) и нажмите **«🎯 Настроить»** в правом нижнем углу. Если кнопка не появилась, проверьте [разрешение Tampermonkey на запуск скриптов](https://www.tampermonkey.net/faq.php?locale=en&q=Q209) и обновите страницу.

## Поиск слотов

1. Выберите существующий приём или направление. Скрипт может создать запись по направлению или перенести существующую. Для первичной записи к врачу без направления сначала запишитесь через сайт, затем выберите этот приём в мастере.
2. Укажите даты, время и адрес. Для переноса можно включить **«Только тот же врач»**. Если из текущей записи не удалось получить идентификатор врача, откройте список врачей в мастере и выберите того же специалиста по имени. При выключенной галочке поиск учитывает всех врачей, которых ЕМИАС предлагает для переноса. Для первого запуска оставьте **«сначала спрашивать»**.
3. Проверьте условия и результат холостого прогона, затем запустите поиск. При подтверждении смотрите на врача, дату и адрес в карточке. После записи или переноса сверьте результат в разделе **«Записи»** на сайте.

Оставьте вкладку ЕМИАС открытой. Поиск проверяет расписание с интервалом от 30 секунд. Он останавливается при выходе или смене полиса, а после перезагрузки страницы его нужно настроить заново. Чтобы остановить поиск вручную, откройте панель со значка и нажмите **«Остановить поиск»**. Если запрос на запись уже ушёл, его результат нужно посмотреть в ЕМИАС.

Если выбранный врач не доступен для переноса, скрипт дождётся его расписания. Если ЕМИАС не позволяет однозначно подтвердить результат переноса, цель останавливается для ручной сверки. Скрипт использует внутренний интерфейс ЕМИАС. Изменения на сайте могут повлиять на его работу.

## Данные

Скрипт отправляет запросы к ЕМИАС от имени текущего пользователя. Настройки поиска и полученные скриптом токены хранятся в памяти вкладки. Скрипт удаляет старую копию токенов `emiasSlotHunter:auth`, если она осталась от исходной версии.

## Разработка

Для сборки и проверок нужен Node.js 18 или новее. Сторонние пакеты не требуются.

```bash
npm test
npm run build
```

Код поиска находится в `core/`, интерфейс — в `userscript/`, проверочные данные и тесты — в `test/`. Сборка записывает `dist/emias-slot-hunter.user.js`.
