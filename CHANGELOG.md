# ЕМИАС: охотник за слотами 0.2.3

Изменения в форке [Hawdey/emias-slot-hunter](https://github.com/Hawdey/emias-slot-hunter) с версии 0.1.7.

## Адреса, дата и время

- Можно отметить несколько точных адресов из списка ЕМИАС. Например, выбрать два подходящих корпуса из четырёх. Все отмеченные адреса видны в холостом прогоне.
- День, диапазон дат и часы по Москве собраны в одном блоке. Для переноса мастер показывает адрес текущей записи. Для новой записи можно выбрать адреса из списка, указать часть адреса или оставить поиск по всем местам, которые предлагает ЕМИАС.
- Если по направлению уже есть запись, мастер предлагает её перенос. Галочка про дорогу оставляет час между приёмами на тот же день по разным адресам. Пересекающиеся приёмы пропускаются всегда.

## Расписание и нагрузка

- Для анализов скрипт запрашивает календарь в обычном 30-дневном диапазоне ЕМИАС, а слоты отбирает по выбранным датам и часам. Это исправляет ошибку загрузки адресов при поиске на один день.
- За цикл поиска или холостой прогон выполняется до шести проверок списков кабинетов и расписания. Между запросами скрипта есть пауза не менее двух секунд. Список кабинетов переиспользуется до двух минут, а свободные слоты проверяются по свежим ответам.
- Если кабинет уже известен по адресу и этот адрес не выбран, его расписание пропускается. При сбое обход продолжается после паузы с оставшихся целей и кабинетов. Для `429` минимальная пауза составляет минуту, а более длинное ожидание из `Retry-After` соблюдается.

## Проверка записи

- Перед отправкой скрипт заново читает список приёмов. Ответ `204` от ЕМИАС считается пустым списком.
- Если выбрано несколько адресов, итоговая запись должна совпасть с адресом конкретного слота. При неопределённом результате скрипт просит сверить запись в ЕМИАС.

## Установка

Скопируйте [готовый скрипт](dist/emias-slot-hunter.user.js) в редактор действующего скрипта Tampermonkey, сохраните его и обновите вкладку ЕМИАС. После этого настройте поиск заново.

Прошли 248 автоматических тестов. В них проверены выбор двух адресов из четырёх, фильтрация расписания и восстановление поиска после ошибки сервера.
